VIM API Docs

Documentazione iniziale delle API sviluppate nel plugin Quivi.Profile. Base URL locale: http://localhost:8085.

Ambiente

Base URL: http://localhost:8085

Formato: JSON

Header consigliati: Accept: application/json, Content-Type: application/json

Credenziali test

Username: demo

Password: demo.123

Postman

Collection: vim-api.postman_collection.json

La richiesta di login salva automaticamente la variabile collection access_token.

Autenticazione

Gli endpoint protetti richiedono un bearer token JWT nell'header Authorization.

Authorization: Bearer {{access_token}}

Il token viene emesso con algoritmo HS256. La durata predefinita e 3600 secondi, configurabile tramite JWT_TTL in minuti.

POST/api/v1/users/login

Autentica un utente registrato e restituisce un token JWT.

Body JSON

Campo Tipo Obbligatorio Note
login string Si, se manca email Username dell'utente.
email string Si, se manca login Email valida dell'utente.
password string Si Password dell'utente.

Esempio richiesta

curl -X POST http://localhost:8085/api/v1/users/login \
  -H "Accept: application/json" \
  -H "Content-Type: application/json" \
  -d '{"login":"demo","password":"demo.123"}'

Risposta 200

{
  "access_token": "<jwt>",
  "token_type": "bearer",
  "expires_in": 3600,
  "user": {
    "id": 2,
    "name": "Demo",
    "email": "demo@vim.it",
    "username": "demo",
    "surname": "Demo",
    "is_activated": true,
    "groups": [],
    "birth_date": null
  }
}

Errori

Status Quando Body
401 Credenziali non valide. {"error":"Invalid credentials."}
403 Utente bannato. {"error":"User is banned."}
422 Body mancante o non valido. {"errors":{...}}

Endpoint protetti gia presenti

GET/api/v1/users/logged

Restituisce il profilo dell'utente autenticato.

PATCH/api/v1/users/profile

Aggiorna i campi profilo supportati: name, surname, username, email, birth_date.

POST/api/v1/users/refresh

Emette un nuovo token per l'utente autenticato.

POST/api/v1/users/logout

Risponde con {"success":true}. Il token JWT resta stateless lato server.
